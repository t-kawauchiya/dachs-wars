## プロジェクト

「腰がいのち ダックス大戦」は、食べ物で相手のダックスフントを釣り、段差を登らせて腰を痛めさせるターン制のブラウザゲーム。pnpm ワークスペースで、次の2つのパッケージに分かれている。

- `packages/core`: ゲームのルール。Phaser にもブラウザにも依存しない純粋な TypeScript
- `packages/client`: Phaser。状態を描き、イベントを演出し、入力をアクションに変える

## コマンド

```sh
pnpm install      # 依存関係のインストール
pnpm dev          # 開発サーバー（ゲーム画面）
pnpm check        # lint・フォーマットの確認（Biome）
pnpm fix          # lint・フォーマットの自動修正
pnpm typecheck    # 型チェック
pnpm test         # テスト（Vitest）
pnpm build        # 公開用のビルド
```
