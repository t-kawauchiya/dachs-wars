# 腰がいのち ダックス大戦

メカで武装したダックスフントたちが、食べ物を撃ち合い、段差で相手の腰を狙うブラウザ対戦ゲーム。

ダックスフントは急な段差で腰を痛めてしまう。重い砲台を積めば強いけど腰に響く。腰から機械の足を生やせば楽になるけど、そのぶん重くなる。
相手を太らせて段差を置くか、お腹いっぱいにして寝かせるか。

## ゲームのルール

ルール、操作、画面について決めたことと、その理由は [docs/game-design.md](docs/game-design.md) にある。

## 開発

Node.js 26（`.node-version` に記載）と pnpm が必要。

```sh
pnpm install      # 依存関係のインストール
pnpm dev          # 開発サーバー（ゲーム画面）
pnpm test         # テスト（Vitest）
pnpm typecheck    # 型チェック
pnpm check        # lint・フォーマットの確認（Biome）
pnpm fix          # lint・フォーマットの自動修正
pnpm build        # 公開用のビルド
```

## 構成

```
packages/
  core/     ゲームのルール。Phaserにもブラウザにも依存しない純粋なTypeScript
  client/   Phaser。状態を描き、イベントを演出し、入力をアクションに変換する
prototype/  最初のプロトタイプ（単体のHTML、ブラウザで開くだけで遊べる）
docs/       ゲームの設計、技術の設計
```

技術選定と設計の方針は [docs/architecture.md](docs/architecture.md) を参照。

## やりたいこと

- 2人対戦（1台で交互に遊ぶ）
- ステージ違い（神社の階段、家の中、坂の多い公園）
- ダックスの種類による性能差（ミニチュア、スタンダード、ロングヘア）
- 段差の駆け引き（スロープで無効化、段差を壊す弾）
- 演出（キャイン、寝落ちの鼻ちょうちん、担架で退場）
- スマホのタッチ操作と16:9画面
- ゲームポータル（CrazyGamesなど）での公開と広告収益化
